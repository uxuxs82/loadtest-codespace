k6 + github codespaces

load test studio

нагрузочный тест в браузере. 500 vu, 1000 минут, два куска по 500. без установки, без карты и без постоянного хостинга.

open in codespaces github
full power preset target https://example.com/ vus 500 total 1000 min chunks 2 x 500 min ramp 5 s think 0 s

что внутри

  • веб-панель с target, vus, duration, ramp-up и think time
  • запоминает последние target, подтверждение каждый раз не нужно
  • кнопка full power на 500 vu и 1000 минут
  • кампания переживает перезапуск того же codespace
  • summary.json и лог каждого куска
  • защита от private и loopback target

лимиты

  • codespace живет максимум 12 часов
  • idle timeout максимум 240 минут
  • 500 минут на кусок, два куска на 1000 минут
  • бесплатно 120 core-hours в месяц
  • полный прогон на 4 ядрах: около 67 core-hours
  • нужен публичный http или https target

как запустить

  1. открой codespaces по кнопке выше.
  2. дождись установки k6 и flask. это минута или две.
  3. открой порт 8000, если вкладка не открылась сама.
  4. впиши свой сайт, он запомнится в браузере.
  5. нажми full power.
  6. после первого куска останови и снова запусти тот же codespace, затем нажми continue campaign.

для продолжения нужен тот же codespace. открыть список: github codespaces. новый codespace начинает кампанию с нуля.

почему два куска

codespace живет максимум 12 часов, это 720 минут. 1000 минут это 16 часов 40 минут. поэтому full power режет тест на два куска по 500 минут. один кусок идет 8 часов 20 минут и влезает в лимит.

после первого куска кампания встает на паузу. перезапусти codespace, открой панель и нажми continue campaign. прогресс лежит в results/ и сохраняется при перезапуске.

постоянная панель

не создавай новый codespace на каждый тест. сделай один и сохрани ссылку на порт 8000 в закладки.

  1. создай codespace один раз.
  2. открой порт 8000.
  3. скопируй адрес вида https://имя-8000.app.github.dev и сохрани в закладки.
  4. дальше открывай эту закладку. если codespace остановлен, github предложит его запустить.
  5. не удаляй codespace, тогда ссылка, настройки и кампания остаются.

это личная панель в codespaces, а не отдельный хостинг. она живет, пока ты не удалишь codespace.

cli из termux

команда сама поднимет codespace, запустит тест и скачает summary.

git clone https://github.com/uxuxs82/loadtest-codespace
cd loadtest-codespace
bash cli/install.sh

k6 https://мой-сайт.ru/ 10 1m
k6 https://мой-сайт.ru/ --full --keep
k6 status
k6 continue
k6 summary --all

нужен gh, авторизованный в github. по умолчанию после теста codespace останавливается, флаг --keep оставляет его для панели.
